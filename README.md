###Prerequisite
<h2>Requirements:</h2>
- [x] g++ or clang++ ( C++ Compiler )

- [x] Make

###<label>1. clone repo</label>
```
git clone https://github.com/FreeNelva/Yris.git
```

###<label>2. installation</label>
```
mkdir build
make install
```
